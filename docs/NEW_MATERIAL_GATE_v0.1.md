# New Material Gate v0.1

**Status:** DERIVED design spec; thresholds are HYPOTHESES

## Evidence base

**EVIDENCE**
- Instructional support should change with learner expertise; novice learners often benefit from more guidance, while redundant guidance can become counterproductive as expertise grows.
- Prior knowledge interacts with learning through multiple mechanisms including comprehension, chunking, cognitive load, transfer and interference; it is not a single monotonic “more is always better” variable.
- In L2 learning, spaced retrieval can improve delayed/automatized learning, but exact optimal schedules are task- and retention-dependent.

## Derived product rule

Do not ask:
`Has the learner mastered Lesson 3?`

Ask:
`Are the prerequisites needed for the next learning act sufficiently available?`

A learner may therefore advance in speaking/listening while a non-prerequisite writing relation remains weak.

## Three gates

### 1. Comprehension gate
Can the learner understand enough known material for the new item/context not to become noise?

If no:
- reactivate prerequisites;
- reduce simultaneous novelty;
- add scaffold.

### 2. Production-load gate
Does the next task require too many unstable elements to be produced simultaneously?

If yes:
- hold one variable constant;
- provide a model/slot;
- split the production demand.

### 3. Review-backlog gate
Is there a meaningful backlog of foundational due material that the next content depends on?

If yes:
- perform targeted retrieval first;
- still allow some new material unless the prerequisite failure is severe.

## What does NOT block progression

- one error;
- weak handwriting when next task is listening;
- imperfect tone production when next task only requires reading comprehension;
- one overdue non-foundational item;
- failure caused by a help/UI misunderstanding.

## What may temporarily block a specific next task

- repeated inability to understand a prerequisite phrase without strong help;
- inability to discriminate a sound contrast required for the next pronunciation task;
- inability to retrieve a construction needed to perform the next free-production task.

Block the **task**, not the entire course.

## Novelty budget

V0.1 should track how many unstable elements a task introduces simultaneously.

Possible novelty dimensions:
- new meaning;
- new sound form;
- new grammatical relation;
- new orthography;
- new motor pattern;
- new interaction demand.

**HYPOTHESIS:** Early tasks should usually introduce one major new demand while other dimensions are scaffolded/known.

This is not a fixed “one new thing per screen” law.

## Engine behavior

If performance is strong:
- reduce scaffold;
- increase retrieval distance;
- introduce more new/transfer content;
- skip redundant review.

If performance is mixed:
- continue curriculum where prerequisites allow;
- target weak relations separately.

If performance is poor on prerequisites:
- reactivate;
- simplify next task;
- delay only the dependent new material.

## V0.1 test

Observe whether the learner experiences:
- boredom from excessive review;
- overload from too much simultaneous novelty;
- artificial blockage caused by one weak modality.

Adjust thresholds from real use rather than claiming scientifically optimal cutoffs.
