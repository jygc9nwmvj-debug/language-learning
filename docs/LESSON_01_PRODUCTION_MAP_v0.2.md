# Lesson 1 — Production Content Map v0.2

**Status:** SOURCE-CHECK REQUIRED BEFORE AUTHORITATIVE USE

## Can-do
After the first learning cycle the learner can:
- recognize/use 你好;
- understand a simple name question;
- answer with 我叫 + own name;
- recognize/use 謝謝/谢谢 and 再見/再见 in context;
- understand that lexical tone changes meaning;
- recognize 我, 你, 好;
- write 好 from memory at an introductory level;
- have guided writing exposure to 我 and 你.

This is not mastery of the four tones.

## Mastery targets

| 我 | active | active | active | active | guided |

## Core utterances
Traditional: 你好。 / 我叫 [Name]。 / 你叫什麼名字？ / 謝謝。 / 再見。  
Simplified: 你好。 / 我叫 [Name]。 / 你叫什么名字？ / 谢谢。 / 再见。

## Tone discovery
mā 媽/妈 · má 麻 · mǎ 馬/马 · mà 罵/骂

These are a meaning-changing-tone demonstration, not vocabulary targets.

## Tone 3 constraint
Never teach Tone 3 as “always a full V”. Distinguish lexical tone from natural connected-speech realization. Use natural phrase audio for 你好.

## Writing
Recall target: 好.  
Guided exposure: 我, 你.  
No calligraphy score.

## Optional discoveries
- 馬/马 pictorial history;
- 好 components 女 + 子, with mnemonic explicitly labeled;
- Laozi line 千里之行，始於足下 only after source/wording verification.

None assessed.

## Humor
At most 1–2 light moments. Do not introduce vocabulary solely for a joke.

## Delayed recall
Later check:
- hear 你好 → understand;
- hear name question → answer;
- recognize 我/你/好;
- write 好;
- one tone contrast.

## Deferred
是, 嗎/吗, numbers, nationalities, 您, full Pinyin inventory, full sandhi theory, radical lists, HSK framing.

## Public-release QA
Phrase audio; Tone 3 explanation; name-question naturalness; 謝謝/再見 audio; ma demo; 馬 history; 好 note; literature attribution.
