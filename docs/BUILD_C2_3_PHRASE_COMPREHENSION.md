# C2.3 — Phrase & Hanzi Comprehension

2026-09-28. Implemented within Learning Architecture v0.1. D remains at **28 additional objects**; total inventory remains **44 canonical words, 36 items, 130 tasks, 76 production audio references**. No new content or audio, no replacement scheduler, no larger design pass.

1. **Canonical model.** Optional item `exploration` defines ordered units with canonical `words`, authored numbered `syllables`, contextual `gloss`, optional `audioItem` and selected character-role notes. Forms resolve from the existing lexicon. No runtime segmentation or translation inference. See [authoring contract](CONTENT_SCHEMA.md#9-implemented-mandarin-phrase-authoring-contract-c23-2026-09-28).
2. **Alignment.** Each Hanzi and its Pinyin share one column; lexical units wrap together. Large Chinese script remains primary. Neutral syllables have no accent; question punctuation remains outside the mapping. Surface tones are displayed only where already explicitly authored; canonical tones/assessment remain separate.
3. **Exploration.** Tap a unit for inline form, Pinyin and contextual meaning. Existing exact-unit audio is offered where available. Tap the same unit, outside, Escape or Schließen to close; another unit changes focus. Optional “Zeichen ansehen” reveals selected character-role explanations and writing-target status. No modal, navigation or external dictionary.
4. **Compounds.** 一點 is one unit meaning “ein bisschen / etwas”; its two Hanzi remain visibly aligned. Character notes explain their role in that expression instead of inventing literal standalone translations. 你好 is taught as a greeting, with secondary character exploration. 一遍 groups two existing word references into one explanation unit.
5. **Explanatory copy.** `learning.note` / `discovery` now support canonical word references with mandatory glosses. Renderer supplies form, Pinyin and gloss. All existing raw Hanzi occurrences in those fields were migrated, including 請, 謝謝, 很, 呢, 德國/人 and number references. Other prose remains plain text. This is a content-field contract, not a general NLP scan of arbitrary UI/source strings.
6. **Script policy.** Existing session preference remains authoritative: Traditional by default, Simplified when selected through existing settings. Phrase and explanatory references derive from the same canonical script field. No new script-switching feature. The previous 請 / 请 explanatory mismatch cannot be reintroduced through these fields.
7. **Scaffolding and retrieval.** New encounters show supporting aligned Pinyin when their reference is revealed; familiar items initially hide it behind “Pinyin zeigen” or unit exploration. Familiarity means prior completed encounter/task or attention completion, not mastery. Unresolved reading has non-tappable Hanzi and no Pinyin; unresolved text/audio recall has no explorable answer. “Hilfe zeigen” reveals the reference and records assistance; after evaluation exploration is available. C2.2's separate tone and Hanzi focus remains; only its final connected surface gains exploration. No tone-assessment gate was broadened.
8. **Validation.** Build rejects uncovered/reordered phrase units, inconsistent syllable counts/bases/tones, unknown canonical references, invalid character indices, mismatched unit audio references, raw unexplained Hanzi in explanatory fields and inconsistent script pairs. New multi-character items require segmentation. An explicit allowlist preserves 15 pre-existing unannotated items. Structural checks cannot establish semantic correctness of authored glosses.
9. **Writing repeat.** Final success is saved once; “Weiter” and optional “Noch einmal” appear. Repeat uses the same target and last scaffold, preserving actual stroke geometry. Its results/errors/hints are optional-practice events, with no additional scheduled attempt, mastery gain or remediation. Weiter remains available during a voluntary repeat. Earlier guided fading stages are unchanged. This intentionally replaces automatic departure after final writing success with one explicit Continue choice.
10. **Previous object.** “Vorheriges” opens only the immediately preceding step of the current session. The live step stays mounted but hidden/disabled: input and cursor survive. Its active-time counter pauses during inspection. Reference playback is stopped before switching. Optional answers, recordings and writing use isolated inspection callbacks/events; no relation or session-plan write occurs. Return via “Zur aktuellen Aufgabe” or Weiter. During an unresolved scheduled text/read/listen/tone recall, looking back is explicitly logged as assistance; a later actual submission follows the existing assisted-attempt rules. No retroactive rewriting of a completed attempt. D ignores optional/inspection events, including recall eligibility checks. Back ≠ retry ≠ voluntary repeat.
11. **Migrated phrases.** 你好 (`nihao`), 我叫 … (`wojiao`), 你叫什麼名字？ (`askname`), 我聽不懂 (`dont-understand`), 請再說一遍 (`say-again`), 請說慢一點 (`speak-slowly`). Structured explanatory references also migrated as listed above.
12. **Still unsegmented.** 謝謝, 再見, 什麼, 我不知道, 不客氣, 對不起, 沒關係, 晚安, 你好嗎？, 我很好, 你呢？, 德國, 中國, 你是哪國人？, 我是德國人. They retain the existing plain reference presentation until authored; no inferred segmentation is shown.

Four focused browser scenarios in Chrome and WebKit: **8 distinct cases passed**, covering mobile exploration/script/Pinyin behavior, assisted recall, previous-practice DB isolation/input retention, and two actual pointer-drawn 好 productions without extra mastery. Additional representative assertions cover 你好's connected pilot and question/neutral syllables in 你叫什麼名字？. Inspected 320/390px screenshots. Initial test-fixture naming errors were corrected; a WebKit Escape/focus issue and explanatory whitespace bug were found and fixed. Only affected tests/build repeated after fixes. No A1/A2 acceptance round, Build-B handwriting matrix, all-D manual pass or broad regression suite.
