# C2.3 — Phrase & Hanzi Comprehension

2026-09-28. Implemented within Learning Architecture v0.1. D remains at **28 additional objects**; total inventory remains **44 canonical words, 36 items, 131 tasks, 76 production audio references**. No new vocabulary or audio, no replacement scheduler, no larger design pass.

1. **Canonical model.** Optional item `exploration` defines ordered units with canonical `words`, authored numbered `syllables`, contextual `gloss`, optional `audioItem` and selected character-role notes. Forms resolve from the existing lexicon. No runtime segmentation or translation inference. See [authoring contract](CONTENT_SCHEMA.md#9-implemented-mandarin-phrase-authoring-contract-c23-2026-09-28).
2. **Alignment.** Each Hanzi and its Pinyin share one column; lexical units wrap together. Large Chinese script remains primary. Neutral syllables have no accent; question punctuation remains outside the mapping. Surface tones are displayed only where already explicitly authored; canonical tones/assessment remain separate.
3. **Exploration.** Tap a unit for inline form, Pinyin and contextual meaning. Existing exact-unit audio is offered where available. Tap the same unit, outside, Escape or Schließen to close; another unit changes focus. Optional “Zeichen ansehen” reveals selected character-role explanations and writing-target status. No modal, navigation or external dictionary.
4. **Compounds.** 一點 is one unit meaning “ein bisschen / etwas”; its two Hanzi remain visibly aligned. Character notes explain their role in that expression instead of inventing literal standalone translations. 你好 is taught as a greeting, with secondary character exploration. 一遍 groups two existing word references into one explanation unit.
5. **Explanatory copy.** `learning.note` / `discovery` now support canonical word references with mandatory glosses. Renderer supplies form, Pinyin and gloss. All existing raw Hanzi occurrences in those fields were migrated, including 請, 謝謝, 很, 呢, 德國/人 and number references. Other prose remains plain text. This is a content-field contract, not a general NLP scan of arbitrary UI/source strings.
6. **Script policy.** Existing session preference remains authoritative: Traditional by default, Simplified when selected through existing settings. Phrase and explanatory references derive from the same canonical script field. No new script-switching feature. The previous 請 / 请 explanatory mismatch cannot be reintroduced through these fields.
7. **Scaffolding and retrieval.** New encounters show supporting aligned Pinyin when their reference is revealed; familiar items initially hide it behind “Pinyin zeigen” or unit exploration. Familiarity now uses dimension-specific meaning introduction, not generic completion or mastery. Unresolved reading has non-tappable Hanzi and no Pinyin; unresolved text/audio recall has no explorable answer. “Hilfe zeigen” reveals the reference and records assistance; after evaluation exploration is available. The consolidated addition below generalizes the focus mechanism by declared dimensions. No tone-assessment gate was weakened.
8. **Validation.** Build rejects uncovered/reordered phrase units, inconsistent syllable counts/bases/tones, unknown canonical references, invalid character indices, mismatched unit audio references, raw unexplained Hanzi in explanatory fields and inconsistent script pairs. New multi-character items require segmentation. An explicit allowlist preserves 15 pre-existing unannotated items. Structural checks cannot establish semantic correctness of authored glosses.
9. **Writing repeat.** Final success is saved once; “Weiter” and optional “Noch einmal” appear. Repeat uses the same target and last scaffold, preserving actual stroke geometry. Its results/errors/hints are optional-practice events, with no additional scheduled attempt, mastery gain or remediation. Weiter remains available during a voluntary repeat. Earlier guided fading stages are unchanged. This intentionally replaces automatic departure after final writing success with one explicit Continue choice.
10. **Previous object.** “Vorheriges” opens only the immediately preceding step of the current session. The live step stays mounted but hidden/disabled: input and cursor survive. Its active-time counter pauses during inspection. Reference playback is stopped before switching. Optional answers, recordings and writing use isolated inspection callbacks/events; no relation or session-plan write occurs. Return via “Zur aktuellen Aufgabe” or Weiter. During an unresolved scheduled text/read/listen/tone recall, looking back is explicitly logged as assistance; a later actual submission follows the existing assisted-attempt rules. No retroactive rewriting of a completed attempt. D ignores optional/inspection events, including recall eligibility checks. Back ≠ retry ≠ voluntary repeat.
11. **Migrated phrases.** 你好 (`nihao`), 我叫 … (`wojiao`), 你叫什麼名字？ (`askname`), 我聽不懂 (`dont-understand`), 請再說一遍 (`say-again`), 請說慢一點 (`speak-slowly`). Structured explanatory references also migrated as listed above.
12. **Still unsegmented.** 謝謝, 再見, 什麼, 我不知道, 不客氣, 對不起, 沒關係, 晚安, 你好嗎？, 我很好, 你呢？, 德國, 中國, 你是哪國人？, 我是德國人. Exact IDs: `xiexie`, `zaijian`, `what`, `dont-know`, `welcome`, `duibuqi`, `meiguanxi`, `wanan`, `how-are-you`, `im-fine`, `and-you`, `deguo`, `zhongguo`, `nationality`, `im-german`. They retain the existing plain reference presentation until authored; no inferred segmentation is shown.
13. **Checks actually run.** Existing automated suite once including four new focused tests: **59/59 passed**. Production validator, TypeScript and build passed. Four focused browser scenarios in Chrome and WebKit: **8 distinct cases passed**, covering mobile exploration/script/Pinyin behavior, assisted recall, previous-practice DB isolation/input retention, and two actual pointer-drawn 好 productions without extra mastery. Additional representative assertions cover 你好's connected pilot and question/neutral syllables in 你叫什麼名字？. Inspected 320/390px screenshots. Initial test-fixture naming errors were corrected; a WebKit Escape/focus issue and explanatory whitespace bug were found and fixed. Only affected tests/build repeated after fixes. No A1/A2 acceptance round, Build-B handwriting matrix, all-D manual pass or broad regression suite.
14. **Normal app.** https://language-learning-abk.pages.dev/ — **Testversion C2.3+ · Inhalte D**. Production audio bytes and accepted hashes unchanged. Learner data stays on the device; no migration/reset is needed.
15. **Best judged in normal learning.** Whether optional word/character exploration helps real comprehension without distracting from recall; whether the current familiarity-based Pinyin reduction is timely; whether final writing choice and previous-object access feel useful. The glosses are concise editorial explanations, not new claims of scientific optimality. Desktop WebKit is useful Safari coverage but not certification of every iPhone interaction.

## Consolidated addition — generalized introduction and Hanzi memory

The user's later consolidated addition extends this same build; it does not replace the phrase work above. All **36 existing objects**, including all 28 D objects, now declare relevant introduction dimensions and role. Profiles: 18 primarily spoken expressions, 10 recognition targets, 8 existing active writing targets. No unique choreography per D item.

- A new spoken expression usually follows focused audio → connected meaning/form, using the existing Weiter. A recognition target adds one Pinyin-free Hanzi-focus action. Explicit tone focus occurs only for declared tone targets; the eight foundation items retain this relevant focus. The initial 你好/好 case still needs two focus actions plus Weiter. Phrase alignment/exploration joins the connected surface, without another compulsory segmentation click.
- Completed focused audio records pronunciation introduction automatically. Tone requires explicit tone-focus acknowledgement and the existing notation prerequisite. Hanzi focus and completed form/sound/meaning association are separate: only the latter records Hanzi introduction. Writing introduction comes from completing guided production. These records describe deliberate teaching opportunities, not measured attention, retention, mastered pronunciation or writing ability.
- Partial introduction resumes only missing focus; fully introduced items use compact display with optional Pinyin. Known whole words in a new combination reuse same-script visual evidence, while new phrase meaning, sound and declared tone still receive relevant introduction. Knowing an entire phrase never automatically declares its characters individually known.
- Before read/listen/text-recall/number-transfer assessment, missing required dimensions convert that occurrence into encoding without an attempt. The UI says Kennenlernen; later assessment says Aus dem Gedächtnis with support initially hidden. A writing recall without guided-writing evidence becomes existing guided production, not blank assessment. Recognition alone never authorizes independent writing. No extra screens or mode banners.
- Existing D scheduling still mixes modalities, spaces later attempts and inserts separated retries. One additional reading task for the existing 你好 makes its recognition target available to that same scheduler. Total is therefore 131 tasks rather than the initial 130; vocabulary remains 36 items. No separate Hanzi scheduler, new spacing constants or massed copying. Existing full-correction behavior on some failed tasks is not replaced by a new feedback engine here.
- Previous-object practice remains isolated, including any introductory actions inside inspection. Voluntary writing repeat remains ungraded. Structural memory support can use authored secondary character notes later; no radicals, folk etymologies or mnemonic generator were added.
- Compatibility: completed old C2.2 focus plus connected-step completion and actual guided-writing completion can support their corresponding dimensions. Generic historical Pinyin/display/completion is insufficient. Some previously displayed D items may therefore receive one proper introduction; nothing is reset or removed.

**Additional verification:** 21 distinct focused unit tests across introduction, attention, phrase integrity and existing D rules passed. The final introduction/comprehension browser run covered **16 distinct cases** across Chrome/WebKit, all passed after correcting a test selector that also matched the hidden worksheet. Includes first/partial/known introductions, known components, no premature reading, writing vs recognition, blocked audio not authorizing listening, and the previous Back/Repeat/hint invariants. Only affected cases were repeated after corrections. The partial-introduction case was extended through guided paper-writing completion and subsequent independent recall to verify that saving evidence cannot change the current writing configuration mid-sequence. The audio case additionally verifies that a later completed reference replay records the missing pronunciation introduction without restarting the connected surface. Production build passed with 44 words / 36 items / 131 tasks / 76 audio references; representative 320px Hanzi-focus screenshot inspected. Historical pilot test expectations were aligned with the new association-completion semantics, without running its old full browser matrix.

**Remaining gaps:** the same 15 older expressions still lack segmentation; all nevertheless have introduction profiles. The one-to-one authored Hanzi/syllable model remains deliberately limited. Semantic gloss quality, whether the focus actually improves delayed character memory, and the usefulness/cost of one extra Hanzi-focus action require normal learning. Introduction evidence is not evidence of effectiveness.

Stop here. No further vocabulary expansion, dictionary integration or Product Design work is included.
