# Corrective Feedback Policy v0.1

**Status:** Evidence-informed; implementation rules DERIVED; thresholds HYPOTHESIS.

## EVIDENCE

- Corrective feedback can facilitate second-language learning.
- Failed retrieval can support later learning when followed by corrective feedback.
- There is no universal empirical answer that one feedback timing is optimal for every L2 task/modalitiy.
- Feedback effectiveness depends on factors including explicitness, task, modality, proficiency and target feature.
- Retrieval practice itself has robust benefits for later retrieval.

## DERIVED principle

Feedback serves two different jobs:

1. **Learning correction** — establish the correct mapping/form while the error is still relevant.
2. **Diagnostic scheduling** — tell the engine what relation needs later retrieval.

Do not confuse feedback with punishment or with an obligation to repeat the identical task immediately.

---

## 1. Closed retrieval tasks

Examples:
- `我` → meaning?
- audio `hǎo` → identify form
- write target character
- discriminate tone pair

After a meaningful error:
1. clearly indicate mismatch;
2. provide the minimum useful correction/model;
3. allow inspection/replay;
4. record the failed relation/help required;
5. move on unless an immediate motor correction is necessary;
6. retrieve the relation again after spacing.

Avoid:
`wrong → same question → wrong → same question`.

---

## 2. Writing/motor feedback

Some motor errors need immediate local correction because the learner is currently executing the movement.

Example:
- wrong stroke direction/order → show next useful cue and let learner retry that stroke.

But after the writing sequence:
- leave the item;
- test free recall later.

Immediate motor correction and spaced memory retrieval are different functions.

---

## 3. Pronunciation feedback

Prioritize one actionable feature at a time.

Bad:
`Your pronunciation is 63%. Tone, vowel and rhythm are wrong.`

Better:
`The second syllable stayed almost level. Try a clearer rise.`

If signal confidence is weak:
- do not diagnose;
- provide reference/listen-compare/retry.

Do not correct every minor accent difference that does not serve the current learning objective.

---

## 4. Communicative production

During a mini-dialogue, correction is selective.

Correct immediately when:
- meaning breaks;
- target construction is the explicit learning focus;
- pronunciation error changes/obscures the intended word;
- repeated error is becoming entrenched in the current task.

Defer/ignore temporarily when:
- communication succeeds;
- the error is outside the current objective;
- correction would overload the learner or destroy the communicative arc.

After the interaction, one concise feedback item may be more useful than interrupting every turn.

---

## 5. Explicitness ladder

Possible feedback levels:

1. `Try once more.` / clarification prompt
2. focused cue
3. contrast / highlight problematic part
4. correct model
5. short metalinguistic explanation

Use the least level likely to produce useful noticing/correction.

Do not force discovery through repeated guessing when the learner lacks the knowledge.

---

## 6. Error classification

Record errors by relation, not as global failure.

Possible classes:
- meaning confusion
- orthographic confusion
- pronunciation/tone
- construction/grammar
- motor/stroke
- task/UI misunderstanding
- unknown/low-confidence

A UI misunderstanding should not reduce language mastery.

---

## 7. Error recurrence

One error = weak evidence.

Repeated same relation across separated opportunities = stronger evidence.

Engine response can escalate:
- first: correction + later retrieval;
- repeated: more scaffold / contrast / brief explanation;
- persistent: targeted micro-block before returning to normal flow.

Never create endless remediation.

---

## 8. Emotional tone

Feedback is neutral and specific.

Prefer:
- `Not yet. 我 means “I”.`
- `Almost — you remembered the sound, but not the character yet.`
- `The meaning was right; the tone needs another pass.`

Avoid:
- celebratory hype for every correct answer;
- red failure theatrics;
- shame/loss framing;
- vague `Wrong!`.

---

## 9. HYPOTHESES to test

- how many separated errors trigger a micro-block;
- when a clarification prompt is better than immediate model;
- how much pronunciation feedback fits in one attempt;
- whether communicative feedback is best immediately after turn vs after mini-dialogue;
- exact delay before retry.

These are prototype parameters, not scientific constants.
