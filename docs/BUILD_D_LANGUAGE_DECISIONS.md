# Build D — language decisions and sources

## Authoring/source decisions

- Repair language is authored as short usable chunks, not a lesson on potential complements. [Yoyo Chinese's potential-complement reference](https://cdn.yoyochinese.com/attachment/PDF/LectureNotes/CHG-Lesson-058-LN.pdf) confirms 听不懂/聽不懂 and lexical bù. Our canonical data keeps bu4 while the separately authored spoken phrase uses weak bu5; neither choice is newly graded.
- 请再说一遍 is the polite repetition request; [LTL's 再 grammar reference](https://flexiclasses.com/chinese-grammar-bank/how-to-use-%E5%86%8D/) supports this usage. 一 remains lexical yi1, with yi2 before biàn and yi4 before diǎn authored only for speech.
- 你好吗 is retained as a question about someone's wellbeing, not an automatic greeting to every stranger. [ChineseClass101's greeting discussion](https://www.chineseclass101.com/lesson/fun-easy-chinese-1-how-to-say-hello) distinguishes contexts and alternatives; the restricted learner-facing context is an authoring judgment, not a claim that the expression is ungrammatical.
- 很 in 我很好 need not carry emphatic “very”; [the introductory particles reference](https://human.libretexts.org/Bookshelves/Languages/Chinese/Introductory_Chinese_Grammar_I_-_under_construction/01%3A_Parts_of_Speech/04%3A_Particles) supports returning a question with 呢. No exercise scores the grammar label or neutral tone.
- 没关系/沒關係 is an answer to an apology or reassurance. [Han Trainer's dictionary](https://dictionary.hantrainerpro.com/chinese-english/translation-meiguanxi_itsnothing.htm) supports the meaning and neutral final syllable; Traditional 係 is selected consistently in our canonical script mapping. Neutral tone choices follow the selected mainland reference style, not every regional variant.
- 晚安 is a late-evening farewell/before-sleep expression, not a generic evening arrival greeting. Its apostrophe is derived automatically: wǎn'ān. Country names may be capitalized; casing is never assessed.
- Ten numbers share three reconstruction tasks and two optional discoveries total (the first three strokes, and country + 人). No gesture images or proverb were added.

This report is the explicitly allowed fallback for a future independent AI review step. The authoring assistant did not impersonate a second independent reviewer. Human/native review remains open; no new runtime API, orchestration system or learner checklist was introduced.
